=== Virtual Try-On for WooCommerce ===
Stable tag: 0.1.0
Requires at least: 6.3
Requires PHP: 7.4

Adds a "Try it on" button to WooCommerce product pages.

== Installation ==
1. Zip the `tryon-for-woocommerce` folder and upload it in Plugins → Add New → Upload Plugin.
2. Activate it, then open Settings → Virtual Try-On and enter the try-on host and your store id.
3. Make sure each product's slug matches its id in the try-on catalog.
